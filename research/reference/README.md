# Reference material for the agents

Fill these in so analyses match your bank's own definitions. Agents should read this folder before analyzing.

- **Ratio definitions** – e.g. your NIM, CASA, NPL, credit cost formulas.
- **Standing assumptions** – cost of equity, risk-free rate, long-term growth, peer list.
- **Regulatory thresholds** – CAR minimum, LDR limit, etc.
- **Example report** – a past report whose style and depth you want reproduced.
